# HelpMeYap

HelpMeYap is a lightweight speaking-drill web app inspired by SpeakUp-style coaching.

## Features

- Instant random speaking topics
- 1–2 minute drill timer (60/90/120 seconds)
- Built-in audio recording and playback
- AI-style speaking feedback on:
  - filler words
  - pause patterns
  - clarity & delivery
- Actionable tips to improve, not just practice

## Run locally

Open `index.html` in a browser.

## Run tests

```bash
npm test
```
